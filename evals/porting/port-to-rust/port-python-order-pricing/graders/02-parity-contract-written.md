A parity contract (a written statement of what "same behaviour" means) exists as a file or a section in the repo. It states: the end state (full replacement of the Python, a Rust core behind a permanent binding, or a temporary scaffold binding); the unit of parity (what is compared, for example the JSON receipt); the acceptable differences; the unacceptable differences; and how parity is measured (a named corpus of inputs and a reported count). It names error exit codes (or the error class) and numeric results as unacceptable differences.
