# Misc skills

Shipped in the plugin as well as the `npx skills` route — occasional setup and
audit skills. The bucket means frequency of use, not availability.

## Model-invoked

- [rust-supply-chain](./rust-supply-chain/SKILL.md) — Advisories, licences, and duplicate dependencies, each ending in a decision.
- [rust-macros](./rust-macros/SKILL.md) — Macros as a last resort, by-example first, with errors that point at the caller.
- [rust-serde](./rust-serde/SKILL.md) — Serde as the validating boundary between a wire format and a domain type.

## User-invoked

- [setup-rust-ci](./setup-rust-ci/SKILL.md) — GitHub Actions workflow for a Rust repo.
- [setup-rust-pre-commit](./setup-rust-pre-commit/SKILL.md) — Fast format and lint hooks, with CI left as the gate.
