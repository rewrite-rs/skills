# Misc skills

Not shipped in the plugin — occasional, provider-specific skills. Reachable
through the `npx skills` install route, not through the Claude Code plugin.

## Model-invoked

## User-invoked

- [setup-rust-ci](./setup-rust-ci/SKILL.md) — GitHub Actions workflow for a Rust repo.
- [setup-rust-pre-commit](./setup-rust-pre-commit/SKILL.md) — Fast format and lint hooks, with CI left as the gate.
