# Workflow skills

Review, testing, setup, and router skills that hold a port or a rewrite together
end to end.

## Model-invoked

- [rust-code-review](./rust-code-review/SKILL.md) — Two-axis review — standards and spec — over a Rust diff.
- [rust-testing](./rust-testing/SKILL.md) — Tests that fail when behaviour changes, including port parity.

## User-invoked

- [setup-rust-skills](./setup-rust-skills/SKILL.md) — Lint, format, and recorded project posture for a Rust repo.
- [rust-skills-map](./rust-skills-map/SKILL.md) — Router over the skill set — which skill owns which decision.
